# Power Apps Code Apps

O app Vite aqui é um **cliente do backend Next.js**, compartilhando a UI de `../src/components`. Ele não executa APIs Node dentro do Power Apps.

Execute `npm install`, configure `.env.local`, então `pa app init`, `npm run build` e `pa app push`. Leia o README na raiz para requisitos de Entra, CORS, segurança e implantação da API.
